# VaultBook

本地账号速查本。打开就能看、点一下就复制、粘一段文字自动认出账号密码；在系统里挂上自动填充后，登录网页也能自动填。

**不联网** —— 安装包里没有 `INTERNET` 权限，数据只存在这台手机上。

| 项 | 内容 |
|---|---|
| 应用名 / 项目名 | VaultBook |
| 版本 | 1.6（versionCode 160） |
| 包名 | `com.yg.vaultbook` |
| 系统 | Android 8.0（API 26）～ API 35 |
| 安装包 | `dist/VaultBook-1.6.apk`，7.07 MB，只含 `arm64-v8a` |

## 功能

### 列表

- 搜索覆盖标题、账号、网址、**备注**，以及**拼音首字母**（输 `zfb` 就能找到「支付宝」）
- 筛选条：全部 / 收藏 / 有内容的分类（带条目数）
- 排序可选：最近使用（默认，收藏优先）/ 按名称（拼音）/ 最近新建 / 按分类，选完记住
- 每条左边一道配色竖条和同色渐变头像，右边一个「复制」块；点进详情，长按弹动作单

### 记录

- 字段：标题、账号（**可以空着**，只存「平台名 + 密码」也行）、密码、网址、备注、TOTP 密钥、分类、收藏、自定义字段
- 密码有强度评分，改密码保留历史
- 详情页看密码、复制、编辑、删除
- 编辑页九项全都能改，保存按钮常驻底部；改到一半点返回会先问一句，不会把刚写的密码丢掉
- 分类 34 个内置（登录、邮箱、社交、购物、支付、银行、证件、工作、学校、网盘、外卖、快递、路由、订阅……），新建条目时点开可搜索（拼音首字母也行），列表底部能就地新建

### 录入

| 方式 | 说明 |
|---|---|
| 手动输入 | 常规表单 |
| 粘贴框 | 新建页顶部是一个多行文本框，粘进去或直接敲，底下实时显示认出了什么，点「填入表单」才写进表单 |
| 智能识别 | 认 `账号：xxx 密码：yyy` 这类键值对（冒号、等号、空格都行），表头自动跳过，行首序号和整行横线剥掉，`备注：…` 不进记录；认反了卡片上有个「账号密码反了？」一键对调 |
| 多组粘贴 | 一次粘好几条（一行一条 / 空行分段 / 横线分隔 / 连着写都行），预览后一次存入，可勾「只存标题和密码」不带账号，重复的不再存第二遍 |
| 连写识别 | `某某平台密码abcd1234`、`账号admin密码abc123` 这种直接粘在一起的，按「中文/数字交界」切开；`抖音12313213` 会把平台名剥出来当标题，不整串当账号 |
| 系统分享 | 在别的应用选中文字 → 分享到 VaultBook，直接进新建页 |
| 无障碍捕获 | 在浏览器或别的 App 登录页输入账号密码，识别后提示保存（只读，不代替你点击） |
| 登录后保存 | 用自动填充登录成功，系统提示是否存进 VaultBook |

### 复制与桌面

- 点「复制」把密码写进剪贴板，**30 秒后自动清空**（Android 13+ 标记为敏感内容）
- 桌面小组件 4×2：最常用的三条，点一下直接开详情复制
- 长按桌面图标：新建 / 生成密码两个快捷方式

### 密码工具

- 生成器：可调长度与字符集，实时显示强度
- TOTP：存了密钥就显示动态验证码，带倒计时

### 备份与检查

- **加密备份**：导出 `.vbc`（自带密码，与手机无关），换机导回去
- **表格导入**：CSV / Excel 导出的表格直接导入，自动认分隔符与中英文表头，先预览再写入，同名的跳过
- **备份提醒**：设置页显示上次备份是几天前，超过 30 天提醒
- **安全体检**：列出弱密码、重复使用的密码、半年没换过的、没存密码的条目，点一下直达
- **回收站**：删除先进回收站，可单条恢复或**一次全部恢复**，30 天后自动清理；列表页删完的提示条上直接有「撤销」，设置页「整理」段第一行是常驻入口并显示条数
- **审计日志**：记录新建、修改、复制、导入导出的时间与对象（不含密码内容）

### 外观

- Material 3，深浅两套配色，跟随系统深色模式；冷启动窗口底色也跟随，不闪白
- 列表页顶部是一行品牌标识加计数，底下垫一层从主色淡出的渐变，不做整块色板
- 筛选条右侧一个排序胶囊，点开四项，当前项打勾
- 设置页最上面一段「系统服务」，自动填充与无障碍识别各显示「已开启 / 未开启」，点一下跳到对应系统开关，从系统页返回立刻重读状态
- 每条记录按网址/包名/标题哈希出一个配色，用在头像、左侧竖条和复制块上
- 次级页统一顶栏（圆形返回键 + 大字标题 + 小字副标题），与首页的圆钮同一套白底细描边
- 卡片统一 20dp 圆角、1dp 阴影，不用描边
- 支持 Android 15 的 edge-to-edge（状态栏/导航栏不走内容）

## 安装

从 [Releases](https://github.com/HalfDone03/VaultBook/releases) 下载 APK，或本地构建后用 adb：

```bash
adb install -r dist/VaultBook-1.6.apk
```

或双击 `install-apk.cmd`（自动找 adb 与最新安装包），也可以把 APK 拷到手机上点开装。

## 用起来

1. **开自动填充**：系统设置 → 密码与账号 → 自动填充服务 → 选 VaultBook。之后登录网页会出现 VaultBook 的候选。
2. **想让它抓登录页**（可选）：设置 → 无障碍 → VaultBook 增强捕获。只在登录页读输入框，用来提示保存。
3. **加第一条**：点右下角 + ，或把账号密码粘进「智能粘贴」。
4. **找东西**：直接搜，中文、拼音首字母、网址都行。

## 技术

| 项 | 选择 |
|---|---|
| 语言 / UI | Kotlin 2.0 · Jetpack Compose（BOM 2024.10.00）· Material 3 |
| 数据 | Room + SQLCipher（整库加密） |
| 异步 | Coroutines / Flow |
| 导航 | 单 Activity + `sealed interface Screen` 状态机，页面状态用 `rememberSaveableStateHolder` 分槽（没引 Navigation-Compose） |
| 构建 | AGP 8.7 · Gradle 8.9 · JDK 21 · R8 + 资源压缩；release 读 `keystore.properties`，缺失时回落 debug 密钥 |

### 数据怎么存

- 数据库文件整体由 SQLCipher 加密；口令在首次启动时 `SecureRandom` 生成 32 字节，Base64 后存进 `SharedPreferences("simple_vault")`
- 这样做是为了「打开即用」：不设主密码，也就不存在忘记密码打不开库的风险。代价是**能读到应用私有目录的人就能拿到数据**，与手机记事本同级
- 字段层走 `PlainFieldCrypto`（明文进出），加密集中在库这一层

### 三条抓取通道

| 通道 | 角色 |
|---|---|
| `AutofillService` | 系统级主通道，负责「填」 |
| `AccessibilityService` | 覆盖 Flutter / RN 自绘登录页，只读（`canPerformGestures=false`），负责「抓」 |
| WebView | 只处理应用自己的页面 |

### 目录

```
app/src/main/java/com/yg/vaultbook/
├── accessibility/   无障碍捕获（表单识别、浏览器域名表）
├── autofill/        自动填充服务（AssistStructure 解析、候选构造）
├── capture/         捕获通知
├── core/            加密、密钥、匹配、工具（解析、拼音、密码、TOTP）
├── data/            Room 实体与 DAO、仓储、备份（.vbc）、CSV 导入、体检
├── domain/          领域模型（EntrySummary / EntryDraft 等）
├── ui/              Compose 页面与组件
└── widget/          桌面小组件
```

### 构建

```bash
./gradlew :app:assembleRelease
```

需要 `local.properties` 指向 Android SDK；工程路径含中文时 `gradle.properties` 已开 `android.overridePathCheck=true`。

### 测试

```bash
./gradlew :app:testDebugUnitTest
```

27 个测试类、458 个用例：解析、加密、匹配打分、备份格式、CSV、拼音、密码强度、TOTP、排序与去重签名、系统服务组件名解析等。
