# 1.12：语料表二十九组

这一版没有加新功能，只做一件事：往语料表里继续塞「人真的会粘进来的文字」，一条条对着改识别。

语料从十九组二百八十六条涨到二十九组四百五十二条。十组新样本覆盖的场景：浏览器导出的四列表格、同一字段名带平台前缀、字段名被方括号或方头括号包着、斜杠分成三格、链接在前字段在后、裸域名打头、一堆换着写法抄同一件事（全角等号、Excel 前导单引号、「账号是…密码是…」、中文逗号、「账 号」中间夹空格、`Account Name`、服务器日志行、反引号包每一样）、带表头的竖线与制表符表格、YAML 列表、固定宽度两列、聊天记录带时间戳、查询串里带账号密码、中文序号打头、备注写最前面、同一行里两组键用顿号连写。

## 这一轮真正修的是判断层，不是接着堆正则

新形状大多不是「少一个字段名」，而是几处判断互相踩：

- **记录从哪里开始算**。切块时边界停在「账号」那一行，可前面那行单独写的平台名（`京东`）属于这条记录，于是第二条记录永远丢标题。新增 `recordStartOf`：边界先退回行首，上一行若是干净的平台名，再退过它。
- **备注会把后面的键吃掉**。备注的值一旦按「取到行尾」处理，`备注：老账号 平台：微博 账号：wb_40 密码：Wb@404040` 就只剩备注一条。改成先用「下一个字段名」截断，再从那截断处继续认后面的键。
- **有一行不是键值，整段就不许在这条路上收工**。`labeledRows` 原来只要认出至少一行就返回，于是「平台名单独一行」被当噪声丢掉，第二条记录没了标题。现在要求每一行都认出来才算这条路成立。
- **引子行不能当平台名**。`账号密码如下：` 以冒号收尾、又是纯汉字，被判成平台名，真正的「淘宝」反而落空。新增 `dropLeadIn` 与 `LEAD_IN_LINE`，把开头的「…如下：」整行删掉。
- **中文序号与括号壳**。`三、淘宝 tb_54 Tb@545454` 里的「三」被当账号；`【淘宝】`、`(淘宝)` 整段留着括号。前者加 `CN_RANK_PREFIX`，后者统一走 `shellName`。
- **一行里两组键**。`账号 tb_45、密码 Tb@454545、账号 tb_46、密码 Tb@464646` 顿号连写，原来只出一条，字段还错位。现在先按顿号拆成多行再重跑，能出两条就用。
- **值尾巴挂着别的键**（上一版留下的）：`淘宝 账号 tb_20 淘宝 密码 Tb@202020` 的账号带着「淘宝」，靠 `trimSiteTail` 把末词是平台名的尾巴剪掉。
- **标签与值粘在一起**：`acc_23密码=Pw@232323`、`wifi名称：`，用 `UNGLUED_AFTER` 在中间补一个空格再认。
- **JSON/XML 的键名表被正则写坏**：`account(?:\s?id)?` 这种带分组的写法塞进 `split('|')` 得到的集合里，`account` 反而匹配不上，`"account"` 与 `<account>` 全部丢账号。改成 `literalsOf()`，取每个标签 `(` 之前的部分。
- **全角与英文混写**：`Ｕｓｅｒ：` 只把冒号前那一段全角字母转半角（值一个字符都不动——有人密码本身就是全角）；`Account Name:` 先把中间的空格并掉再认。

## 顺带认得的写法

带外层包装的 JSON 数组、XML 的 `<account>` 段、`平台(淘宝) 账号(...) 密码(...)` 括号包值、`platform=微博&account=…&password=…` 查询串、`https://…/login?u=…&p=…`、`tb_13@example.com ---- Tb@131313` 用横线隔开、`mysql -u x -p y` 命令行、`user:pass@host` 连接串、HTML 的 `<tr><td>` 表格、四列带序号或平台名写在最后的制表符行、`【1】淘宝` 的序号残渣、`(淘宝)` 圆括号壳。

## 仍然不认的

- 整段是自由叙述，账号密码散在句子里（「我那个淘宝号是 xxx，密码好像改了」）。
- 只有密码、连平台名都没有，且密码看起来像普通单词。
- 一张表里列顺序每行都不一样、又没有表头。
- 密码里本身带着「账号」「密码」这种字（会被当成新字段名切开）。
- 图片、截图里的文字（这一版仍只处理粘贴进来的文本）。

## 验证

三十个测试类、五百零二例、零失败；其中语料表四百五十二条逐条比对，覆盖上面所有形状。解析器仍在 `core/util/CredentialParser.kt`，语料表在 `app/src/test/.../CredentialParserCorpusTest.kt`，加样本就加一组 `Case`，跑一次就知道哪儿不对。
