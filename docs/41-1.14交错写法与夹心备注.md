# 1.14 · 交错写法、密码带空格、备注夹在中间

## 这一版补的三类

上一版认不出、这次补上的三种写法：

```
淘宝密码Xyz123账号tb_1          平台名 + 密码 + 账号，顺序反着还全粘着
账号：sp_62 密码：Zx8Kq 2Lm7V    密码中间带一个空格
微软账户备注家里用密码Ab@717171   平台名和密码之间夹一句没标点的备注
```

## 为什么以前认不出

1. **交错写法**：这一行真的有两个字段名，但顺序是「密码在前、账号在后」。
   按位置猜时，整段 `淘宝密码Xyz123账号` 被当成平台名、`tb_1` 被当成密码，
   于是三样全错位 —— 标题里带着密码、密码栏里装着账号。
2. **密码带空格**：带冒号或字段名后写空格时其实一直是对的（值取到行尾），
   错的是「平台名 + 密码 + 带空格的值」这种混合写法里，值会被空格截成两段，
   后半段当成多余的字丢掉。
3. **备注夹在中间**：`备注` 后面没有冒号，它就跟平台名糊在一起成了标题，
   而备注内容 `家里用` 也跟着进了标题 —— 备注栏反而是空的。

## 改了什么

- 新增一层「拆交错」判断：标题以账号类字段名（账号／帐号／账户／用户名／登录名）
  收尾、且中间紧跟着一个密码类字段名（密码／口令）时，把这两段对调回
  密码与账号，标题只留最前面的平台名。
- 新增一层「拆夹心备注」：标题里有备注类字段名（备注／说明／注释）、
  它前面还有平台名、后面还有话时，后半段落进备注栏、标题只留平台名。
  只认「前面确实有平台名」这一种，所以 `备注模板` 这种本身就是名字的不会被拆。
- 两处都在结果组装完成之后做，不影响已有分支：先按老规则认，认出来的
  结果里平台名和密码位置不对，再纠正。

## 现在的识别结果

- `淘宝密码Xyz123账号tb_1` → 淘宝 / tb_1 / Xyz123
- `账号：sp_62 密码：Zx8Kq 2Lm7V` → 无平台名 / sp_62 / `Zx8Kq 2Lm7V`（空格保留）
- `淘宝 账号 sp_63 密码 Zx8Kq 2Lm7V` → 淘宝 / sp_63 / `Zx8Kq 2Lm7V`
- `微软账户备注家里用密码Ab@717171` → 微软账户 / 空 / Ab@717171，备注「家里用」

## 验证

- 语料表新增六条同形状样本（值全部编造），总数四百六十五条。
- 三十个测试类、五百零一例、零失败。

## 仍然不认的

- 一行里两个平台名、且没有任何分隔符（`淘宝京东密码Xyz123`）。
- 密码本身含「账号」「密码」这类字样（`密码Ab账号123`），会被当成交错写法拆错。
- 备注里再夹一层括号说明、又没标点的长句。
- 值里有换行（粘贴时被拆成两行的长密码）。
