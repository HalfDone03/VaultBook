# 20 · 体积诊断与瘦身

> 版本：v1.7.0　｜　一句话：**31.80 MB → 10.89 MB（-66%）**，功能一个没少。

## 1. 先看它到底大在哪

把 APK 当 zip 拆开，按条目累加**未压缩**大小（v1.6.0，31.80 MB）：

| 组 | 未压缩 | 占比 | 是什么 |
|---|---:|---:|---|
| `dex` | 26.13 MB | 55% | 编译后的字节码，16 个 `classes*.dex` |
| `lib/x86_64` | 6.09 MB | 13% | **模拟器**用的 SQLCipher |
| `lib/arm64-v8a` | 5.54 MB | 12% | 你的手机真正加载的那份 |
| `lib/x86` | 5.16 MB | 11% | **模拟器**用的（32 位） |
| `lib/armeabi-v7a` | 3.86 MB | 8% | 老 32 位手机的兜底 |
| `resources.arsc` | 0.69 MB | 1% | 资源索引 |
| `res` | 0.37 MB | 1% | 图标、布局 |

三个结论：

1. **四个 ABI 的 `.so` 合计 20.65 MB，其中 11.25 MB 你永远用不到** —— 每个 ABI 一份完整的 `libsqlcipher.so`，而一台手机只加载自己那一个。
2. **dex 26 MB 是 debug 包的必然结果** —— debug 不做 R8、不删未用代码、保留全部调试信息与行号表，并且按 16 个包拆开。release 那份同样代码只有 2.50 MB。
3. 你装的是 debug 包，所以显大；release 包虽然小得多，但之前是 `-unsigned`（未签名，装不上）。

## 2. 做了三件事

### 2.1 只打两个真机 ABI

```kotlin
ndk { abiFilters += listOf("arm64-v8a", "armeabi-v7a") }
```

- `arm64-v8a`：2017 年以后的手机基本都是
- `armeabi-v7a`：老机器兜底
- 砍掉 `x86` / `x86_64`：只有模拟器用，真机永远加载不到

**省 11.25 MB**。这一项是收益最大、风险最小的一刀 —— 你手机上本来就只有一份 `.so` 生效。

### 2.2 release 包用 debug 密钥签

原来没配 `keystore.properties` 时 `assembleRelease` 产出 `app-release-unsigned.apk`，**装不上**，所以只能装 debug 包（31.80 MB）。

现在改成：

```kotlin
signingConfig = if (hasSigningConfig) {
    signingConfigs.getByName("release")   // 有正式密钥就用它
} else {
    signingConfigs.getByName("debug")     // 没有就用 debug 密钥签
}
```

自己装用完全没问题（`apksigner verify` 已确认签名有效，`CN=Android Debug`），只是不能上架商店。

**省 12 MB 左右**（debug 的 16 个 dex → release 的 1 个 2.5 MB dex）。

### 2.3 删掉生物识别全套

"去主密码"改造之后指纹解锁就没有意义了 —— 库本来就不上锁。但代码和依赖还留着，一直白占体积：

- 删 `core/biometric/BiometricKeyStore.kt`、`core/biometric/BiometricUnlocker.kt`
- 删 `VaultGateway` 的 `biometricStore` 字段与五个方法（`hasBiometricEnrolled` / `wrappedDekForBiometric` / `enableBiometricUnlock` / `disableBiometricUnlock` / `unlockWithBiometric`）
- 删依赖 `androidx.biometric` 与 `androidx.fragment`
- `MainActivity` 从 `FragmentActivity` 退回 `ComponentActivity`（当初只是为了承载 `BiometricPrompt`）

## 3. 结果

| | v1.6.0 | v1.7.0 | 变化 |
|---|---:|---:|---:|
| 你装的包 | debug **31.80 MB** | release **10.89 MB** | **-66%** |
| debug 包（备查） | 31.80 MB | 19.34 MB | -39% |
| 未压缩内容 | 47.88 MB | 12.17 MB | -75% |
| 其中 dex | 26.13 MB | 2.50 MB | -90% |
| 其中 `.so` | 20.65 MB（4 ABI） | 9.40 MB（2 ABI） | -55% |

**功能一个没少**：374 项单测全绿、lint 0 error 0 warning，所有页面、自动填充、无障碍捕获、小组件、备份、TOTP 都在。

## 4. 还能再砍多少

只剩一处值得动：**再砍掉 `armeabi-v7a`，只留 `arm64-v8a`** → 再省 3.86 MB，总大小约 **7.0 MB**。

代价：2016 年及更老的 32 位手机装不上（会报「应用未安装 · 与您的手机不兼容」）。现代手机 100% 是 64 位，风险很低但你得确认自己那台是 64 位。

要不要砍，说一声。

剩下的 9.4 MB 里，`libsqlcipher.so` 占 5.5 MB —— 那是**整库加密**的代价，换成不加密的 Room 能到 5 MB 左右，但数据就变成可被任何文件管理器直接读的明文。不建议动。

## 5. 校验

```powershell
# 体积
Get-ChildItem dist\账号本-1.7.0.apk | Select-Object Name, @{n='MB';e={[math]::Round($_.Length/1MB,2)}}

# 签名有效
.toolchain\android-sdk\build-tools\35.0.0\apksigner.bat verify --print-certs dist\账号本-1.7.0.apk
# 期望看到：Signer #1 certificate DN: C=US, O=Android, CN=Android Debug
```
