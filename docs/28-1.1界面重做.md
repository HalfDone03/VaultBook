# 1.1 界面重做：从"能用"到"看着像个软件"

用户反馈原话：「感觉页面还有点丑，你再优化优化。」同时明确排除了四项：应用锁、防截屏、许可证、列表页备份提醒 —— 理由是「应该只有我用」。所以这轮只碰观感，不加功能。

## 一、丑在哪：三个具体病根

不是配色不好看，是三件更基础的事没做：

1. **圆角各写各的**。同一个应用里同时存在 12dp（Card 默认）、14dp、15dp、18dp、20dp、22dp 六种圆角，卡片、按钮、输入框彼此没有共同语言。
2. **没有层级**。列表页顶上是一行字，下面直接叠筛选条和搜索框，全是白的；次级页的标题栏和内容同一个平面，视线落下去找不到入口。**一屏里没有一块"重"的地方**，所以显得平。
3. **颜色只用在小地方**。全屏只有描边和文字用了一点绿，面积最大的区域全是白，看着寡淡。

诊断完，改法就是三件事：一个形状刻度、一块压得住的重色、一套统一的行与标题。

## 二、做了什么

### 2.1 列表页：一块深绿头图

`ListHeader` 从"白底上的一行大字"改成深绿渐变头图：

- 竖渐变 `#11825C → #053726`，下缘 30dp 圆角，`statusBarsPadding()` 之后才有内边距，状态栏区域也吃这块色。
- 标题 `VaultBook` 用 `displaySmall` 白色，副标题「共 N 条 · M 个分类」白色 76%。
- 右上三个圆形玻璃按钮（通知、更多、设置）在深色底上换成白色 16% 的底 + 白色图标。`HeaderAction` 因此加了 `onDark` 参数。
- 搜索框用 `offset(y = -18.dp)` 压在头图下缘上，配 18dp 阴影 —— 这一压把"头图"和"内容"粘在了一起。
- 正文原来的顶部淡绿光晕（`drawBehind` + 径向渐变）删掉了：头图自己已经是深绿，再叠淡绿会把白卡片的边界泡糊。

深绿写死成常量 `HeroTop` / `HeroBottom`，**不取主题色**：深色主题下 `primary` 是亮薄荷 `#4ADE9B`，白字压上去完全糊。

### 2.2 图标的形状刻度：20dp 卡片 + 1dp 阴影

统一成一套刻度，所有页面照抄：

| 元素 | 形状 | 阴影 |
|---|---|---|
| 卡片 | `RoundedCornerShape(20.dp)` | `cardElevation(1.dp)` |
| 列表行 | `RoundedCornerShape(22.dp)` | `cardElevation(1.dp)` |
| 输入框 / 搜索框 | `RoundedCornerShape(16.dp)` | 无 |
| 小胶囊 / 复制块 | `RoundedCornerShape(11.dp)` | 无 |
| 图标色块 | `RoundedCornerShape(12.dp)` | 无 |

顺手把 `EntryRow` 的描边整个去掉（`BorderStroke` 删了）。阴影 + 描边 + 左侧色条三个边界信号同时出现，卡片像贴了层贴纸 —— 留最轻的一层阴影，边界交给白卡片和浅绿背景之间的明度差。

### 2.3 一套顶栏：`VaultTopBar`

原来 10 个次级页各写各的 `TopAppBar`，标题用 `titleLarge`、返回键是标准 `IconButton`。抽成一个组件放进 `Components.kt`：

```kotlin
VaultTopBar(
    title = "备份",
    subtitle = "导出加密文件、导入表格",
    onBack = onBack,
    backIcon = Icons.Filled.Close,      // 需要时换掉返回图标
    backLabel = "关闭",
    actions = { TopBarButton(Icons.Filled.Delete, "清空", onClick = {}, tint = error) }
)
```

- 左侧 42dp 圆形玻璃返回键，按下缩到 0.92。
- 标题 `headlineSmall`、副标题 `labelMedium`，比原来的 `titleLarge` 大一号，跟头图呼应。
- `actions` 里用 `TopBarButton`：同样 42dp 圆形，支持 disabled 和角标。

10 个页面全部换掉，每页都补了副标题（原来只有标题，顶栏空荡荡的）。旧的 `TopAppBar` import 留着没删 —— 只是未使用警告，不影响构建。

### 2.4 设置页：从"四行字"改成三段分组

原来是一条 `Card` 里四行 `SettingRow`，所有东西挤成一片。重写后：

- 三段小标题：数据 / 整理 / 关于（`VaultSectionTitle`，`labelMedium` + `letterSpacing 1.2.sp`）。
- 每段一张 `VaultCard`，行与行之间是左侧缩进 66dp 的分隔线（从文字起始处开始，不从图标开始）。
- 每行左侧 38dp 圆角色块 + 19dp 图标，**颜色跟条目用同一个哈希调色板**（`accentOf("backup")`），所以备份是橙、审计是蓝，不是一片灰。
- 关于改成 44dp 的 "V" 方标 + 版本号 + 条目数。

`Icons.Filled.List` 刻意换成 `Icons.Filled.Menu`：`List` 这个 import 会跟 Kotlin 的 `List` 类型名撞车，在同一个文件里写 `List<Foo>` 就会歧义。

### 2.5 备份页：三个竖排按钮改成一张卡片里的三行

三个 `fillMaxWidth` 的按钮竖着堆，看着像份表单。改成 `VaultCard` 里三行 `VaultActionRow`（导出 / 导入 / 从表格导入），每行一个色块图标 + 标题 + 一句说明，跟设置页同一套语言。CSV 的说明从按钮下方那坨 `labelSmall` 提到副标题里。

### 2.6 其余页面

- **回收站**：行改成"渐变头像 + 标题 + 剩余时间 + 右侧两个胶囊按钮（恢复/删除）"，按钮底色是强调色的 11%。
- **分类管理**：34dp 色块显示分类首字，右侧上下箭头做成 30dp 圆形，第二行右对齐"改名/删除"胶囊；内置分类的删除位写「不可删」且置灰。
- **详情页**：所有 `TextButton` 换成 `CopyGhost`（10dp 圆角、底色 10%、`labelMedium`），"显示/隐藏"和"复制"并排放在密码行右侧。
- **生成密码**：密码本身从"白卡里的一行大字"改成深绿面板（跟列表页头图同一套色），白色等宽字 + 下方一个圆点表示强度（红/琥珀/薄荷）。
- **审计日志、安全体检、待确认**：卡片全部并入 20dp + 1dp。

### 2.7 新增的共享组件

`ui/Components.kt` 里多了 6 个，供各页复用：

`VaultTopBar` · `TopBarButton` · `VaultSectionTitle` · `VaultCard` · `VaultRowDivider` · `VaultActionRow`，加两个色常量 `HeroTop` / `HeroBottom`。

## 三、为什么没做更多

- **不加导航库**：页面只有 11 个、层级最浅两层，`sealed interface Screen` + `when` 已经够；换 Navigation-Compose 是给构建体积和启动时间付账。
- **不引图标库**：只用到核心图标集里的十来枚，为一枚箭头引 `material-icons-extended` 不划算（R8 会裁，但构建要付代价）。复制块就是文字按钮，靠底色和圆角做成"按钮"。
- **不加动画库**：入场动画是 `Motion.kt` 里手写的 `enterFadeSlide`，够用；再加弹簧动画只是让列表滚起来更卡。
- **不做主题色自定义**：只有一个人用，深色模式已经跟系统走，加个取色器属于给未来的自己挖坑。

## 四、验收要点

装在手机上看这几处：

1. 列表页头图是不是从状态栏一路铺下来，搜索框是不是压在绿和白的分界线上。
2. 右上三个白色圆形按钮在深色头图上是否清楚（浅色主题/深色主题各看一次）。
3. 设置页三段分组、每行左侧的色块图标颜色是否各不相同。
4. 备份页三个入口是不是一张卡片里的三行。
5. 生成密码页的面板：白色等宽密码在深绿底上是否清楚，强度圆点颜色是否跟着强度变。
6. 深色模式下所有卡片是不是 `#161B19` 配深色背景，没有刺眼的白块。
