# 03 · 页面设计与交互

## 1. 设计语言

| 项 | 定义 |
|---|---|
| 体系 | Material 3（Material You），支持动态取色（Android 12+），关闭时用固定品牌色 |
| 主色 | 深靛蓝 `#3D5AFE`（Primary）/ 容器 `#E0E6FF` |
| 危险色 | `#D32F2F`（删除、明文导出、解除绑定） |
| 安全色 | `#2E7D32`（强密码）/ `#F9A825`（中）/ `#D32F2F`（弱） |
| 表面 | 浅色 `#FDFCFF`；深色 `#121318`（跟随系统，默认跟随） |
| 圆角 | 卡片 16dp，输入框 12dp，按钮全圆角 |
| 字体 | 系统默认（思源黑体），标题 `titleLarge 22sp/600`，正文 `bodyMedium 14sp`，密码等宽 `Roboto Mono 16sp` |
| 间距 | 8dp 基准网格；页面左右边距 16dp |
| 图标 | Material Symbols Rounded，24dp |
| 层级 | 单 Activity + Compose NavHost；全局底部导航仅 4 个一级入口 |

**状态**：`page1 / page2 / page3`；第 2 页进度条实时反映 `PasswordStrength`（0–4 → 弱/中/强）。

**完成动作**：生成 `kdf_salt` → 派生 `KEK_master` → 生成 DEK 与 dbKey → 写 `vault_meta`（单事务）→ 跳 `Unlock`。

## P2 · 解锁（Unlock）

```
┌──────────────────────────────────┐
│                                  │
│            🔐                    │
│          账号本                   │
│                                  │
│   ┌──────────────────────────┐   │
│   │ 主密码              👁    │   │
│   └──────────────────────────┘   │
│                                  │
│            [  解 锁  ]            │
│                                  │
│        👆 使用指纹 / 面容         │
│                                  │
│   ⚠ 密码错误，还可尝试 4 次        │
└──────────────────────────────────┘
```

**状态机**：

| 状态 | UI 表现 |
|---|---|
| `Idle` | 输入框可编辑，解锁按钮可点 |
| `Deriving` | 按钮变进度环，文字「正在解锁…」，输入框禁用（KDF 300–500ms） |
| `WrongPassword` | 输入框抖动 + 错误文案 + 剩余次数；清空输入 |
| `Backoff(sec)` | 按钮显示倒计时「请等待 30s」，输入禁用 |
| `BioAvailable` | 底部指纹按钮常亮；无生物识别则隐藏 |
| `BioPrompting` | 调起系统 `BiometricPrompt`（CryptoObject） |
| `Wiped` | 「数据已清空」空心页 + 重新开始按钮 |

**交互细节**：
- 冷启动 `autofocus` 到输入框并拉起软键盘。
- 生物识别在 `onResume` 后 800ms 自动尝试一次（可设置关闭）。
- 键盘 Enter 直接提交。
- 解锁成功 → 震动 10ms（可关）→ 淡入首页。

## P8 · 密码生成器

```
┌──────────────────────────────────────────────┐
│  生成器                                       │
├──────────────────────────────────────────────┤
│  ┌────────────────────────────────────────┐  │
│  │  k#9Lm@2vQx!7Rt$             ⟳   📋    │  │  ← 点击文字即复制
│  └────────────────────────────────────────┘  │
│  ▓▓▓▓▓▓▓▓▓▓  很强（约 96 bit）                │
├──────────────────────────────────────────────┤
│  长度                        18  ──●──────    │
│                              (8 ──────── 64)  │
├──────────────────────────────────────────────┤
│  ☑ 大写字母 ABC           ☑ 小写字母 abc      │
│  ☑ 数字 123               ☑ 符号 !@#$         │
│  ☐ 排除易混淆字符 (0O1lI|)                     │
│  ☐ 每类至少一个                                │
├──────────────────────────────────────────────┤
│  预设：[高强度]  [好记的]  [PIN 码]  [自定义]   │
├──────────────────────────────────────────────┤
│  最近生成                                      │
│  k#9Lm@2vQx!7Rt$   [复制]                     │
│  T7$kLp2#vQ9!mX   [复制]                     │
└──────────────────────────────────────────────┘
```

- 生成算法：安全随机 `SecureRandom`（禁止 `Random`、禁止 `Math.random`）。
- 「每类至少一个」开启时先按类各取 1 个再打乱（`Collections.shuffle` 用加密随机源）。
- 长度滑条步进 1；每类开关全关时禁用生成并提示。
- 「好记的」预设：`word-word-word-1234` 词表模式（内置 2048 词精简表或 dashlane 风格，v1 用 400 常用词）。
- 生成历史存 **内存** + DataStore（只存最近 10 条，可选关闭）。

## 3. 全局交互约定

| 场景 | 约定 |
|---|---|
| 危险操作 | 一律红色文字按钮 + 二次确认；「清空数据」三级 |
| 复制反馈 | Snackbar + 剩余清空时间；重复复制同一值不叠加 Snackbar，只更新计时 |
| 加载 | > 300ms 显示进度；解锁/导入用不定长进度环 |
| 错误 | 就地 Inline 错误文案（红），不用 Toast 承载关键信息 |
| 空白态 | 插画 + 一句说明 + 一个主操作 |
| 手势 | 详情页右滑返回；列表项左滑「删除」（进回收站），右滑「收藏」 |
| 震动 | 复制成功 8ms，错误 2×20ms（可在设置关闭） |
| 无障碍 | 所有图标按钮带 `contentDescription`；密码显示切换带 `stateDescription` |
| 深色模式 | 全页面支持；真彩色 icon 在深色下加 40% 白色蒙层 |
| 字体缩放 | 支持到 200%，列表行高自适应，强度条换行 |
