# 1.2 列表页顶部重做

## 1. 问题

用户原话：「软件顶部太难看了，你重新优化优化。」

这是 1.1 那一轮留下的后遗症。1.1 为了「不素」，把列表页顶部做成了一整块深绿渐变板：
`clip(RoundedCornerShape(bottomStart = 30.dp, bottomEnd = 30.dp))` +
`Brush.verticalGradient(listOf(HeroTop(0xFF11825C), HeroBottom(0xFF053726)))`，
铺到状态栏，上面压一行 `displaySmall` 的白色 "VaultBook"，右侧三个 `Color.White.copy(alpha = 0.16f)` 的圆钮，
搜索框再用 `offset(y = (-18).dp)` + `shadow(18.dp)` 负偏移压住色板下缘。

复盘下来三个病根：

1. **整屏第一眼像启动页广告**。一块占掉四分之一屏的高饱和色板，用户在「查账号」这个场景里并不需要品牌墙，它只是把第一屏能看到的记录条数压少了。
2. **浅色主题下状态栏图标看不见**。`enableEdgeToEdge()` 之后，浅色主题里系统状态栏图标是深色的；深绿板垫底，时间、电量、信号几乎糊成一片。这是能一眼看出来的缺陷，不是审美问题。
3. **负偏移 + 大阴影 + 两套圆角打架**。色板自己 30dp 圆角，搜索框 16dp 圆角，还叠 18dp 阴影往外溢，边界读不清楚。

## 2. 改法

### 2.1 拆掉色板，改成一层极淡的主色雾

```
.background(
    Brush.verticalGradient(
        listOf(primary.copy(alpha = 0.10f), primary.copy(alpha = 0.025f), Color.Transparent)
    )
)
```

三段渐变的最后一段是 `Color.Transparent`，所以顶部区域和下面的列表底色之间没有硬边，
不会出现「一块色板切一刀」的分界。取 `primary` 而不是写死深绿，深色主题下会自动变成薄荷绿的低透明雾，白字或深字都压得住。

同时删掉 `HeroTop` / `HeroBottom` 两个常量在 `EntryListScreen.kt` 里的 private 副本
（`Components.kt` 里还有一份 `internal` 的，生成器页面在用）。

### 2.2 标题从「广告文案」改回「品牌 + 状态」

- 7dp 主色圆点 + 9dp 间距 + `headlineMedium` / `SemiBold` / `letterSpacing = (-0.5).sp` 的深色 "VaultBook"，一行排开；
- 下面 `labelMedium` 的计数（`共 N 条 · M 个分类`）用 `onSurfaceVariant`，不再是白色 0.76f；
- 字号从 `displaySmall`（36sp）降到 `headlineMedium`（28sp）。

字体收紧半个 sp 是为了让 "VaultBook" 这九个字母在 SemiBold 下不至于显得松散。

### 2.3 三个入口从「16% 白玻璃」改成「白球 + 极淡描边」

```
.size(40.dp).clip(CircleShape)
.background(colorScheme.surface.copy(alpha = 0.92f))
.border(1.dp, colorScheme.outlineVariant.copy(alpha = 0.55f), CircleShape)
```

`HeaderAction` 上原来的 `onDark` 参数和两套底色分支整段删掉（页面不再有深色底可压），
三处调用去掉 `onDark = true`。

### 2.4 搜索框回到正常流里

删掉 `offset(y = (-18).dp)` 和 `shadow(18.dp, ...)`，改成 `Spacer(10.dp)` → 搜索框 → `Spacer(8.dp)`。
搜索框自己还有 1dp 描边和 16dp 圆角，已经够区分层级，不需要靠阴影硬抬。

### 2.5 内页顶栏按钮同步

`Components.kt` 的 `RowScope.TopBarButton` 原来是 `surfaceVariant.copy(alpha = 0.60f)` 灰球、42dp。
本轮统一成和首页一样的「白球 + 极淡描边」、40dp，`VaultTopBar` 标题补 `FontWeight.SemiBold`。

两处各写一种（首页白球、内页灰球）会让人在内页和首页之间来回切时觉得像两个应用。

## 3. 为什么没做更多

- **没加搜索框常驻聚焦/展开动画**：列表页的主路径是「扫一眼 → 复制」，搜索是次要动作，给次要动作加动效会抢主路径的注意力。
- **没把三个入口收进 ⋮ 菜单**：设置和生成器是高频入口，藏起来反而多一次点击。
- **没换配色**：这一轮只动顶部，全站配色改动面太大，且本机没有真机可验，风险不对等。
- **没做顶部折叠（滚动时头图收缩）**：需要 `nestedScroll` + 高度插值，本机无法目视验收，先不做。

## 4. 验收要点

装上之后看这几点：

1. 顶部不再有整块深绿板，状态栏的时间/电量在浅色主题下清楚可见；
2. 顶部和列表之间没有硬边，往下滑动时不会有色块跟着跑的割裂感；
3. 首页三个圆钮和任意内页的返回键是同一套白底细描边，大小一致；
4. 搜索框不再有外溢的大阴影，和上下的间距是均匀的；
5. 深色主题下顶部是一层很淡的薄荷绿雾，标题是浅色字，不发灰。
